## 📖 Tentang Project Ini

Repository ini berisi:

- **Landing Page** — Website personal untuk mempromosikan brand "Shiro Game" sebagai content creator & game reviewer.
- **Naskah/Script** — Koleksi naskah video review game yang siap produksi.

---

## ✨ Fitur Landing Page

| Fitur | Deskripsi |
|-------|-----------|
| 🌙 Dark Theme | Desain modern dengan gradient ungu & coral |
| 📱 Responsive | Tampil sempurna di mobile, tablet, & desktop |
| ✨ Animasi Scroll | Fade-in effect saat scroll untuk UX yang smooth |
| ⚡ Single File | Satu file HTML, tanpa framework, langsung jalan |
| 🎨 Custom Fonts | Google Fonts (Inter & Space Grotesk) |

## 🚀 Cara Deploy (GitHub Pages)

1. Buka **Settings** → **Pages** di repository ini
2. Pilih branch `gh-pages` dan folder `/ (root)`
3. Klik **Save**
4. Website akan live di `https://logensay62-dot.github.io/kiro-aihelping/`
